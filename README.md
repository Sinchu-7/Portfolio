# Sinchana Poojary Portfolio

This project contains a Vite React frontend and an Express/MongoDB backend for a professional portfolio website.

## Structure
- `frontend/` – portfolio UI and static content
- `backend/` – API layer, validation, MongoDB integration, contact form backend
- `docs/` – documentation and deployment notes
- `.github/workflows/` – CI workflow

## Local development
1. `cd frontend && npm install && npm run dev`
2. `cd backend && npm install && npm run dev`

## Production build
- `cd frontend && npm run build`
- `cd backend && npm run start`
